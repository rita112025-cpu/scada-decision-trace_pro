# mdlinkcheck

`mdlinkcheck` is a dependency-free Python 3.10+ command-line tool that checks
local relative links in Markdown files. It never makes network requests.

## Usage

```console
python -m mdlinkcheck README.md docs/
```

Each argument may be a Markdown file or a directory. Directories are scanned
recursively for files whose extension is `.md` (case-insensitive). Broken links
are printed one per line:

```text
docs/index.md:12:3: missing-file missing.md
docs/index.md:18:1: missing-anchor guide.md#installation
```

The exit status is `0` when every checked link is valid, `1` when broken links
are found, and `2` for invalid arguments, nonexistent paths, or unreadable files.

The checker handles normal links (`[text](target)`) and images
(`![alt](target)`). Targets beginning with `http://`, `https://`, or `mailto:`
are ignored. Relative targets are resolved from the directory containing the
Markdown source file. Percent-encoded paths such as `my%20file.md` are decoded.

## Heading anchors

ATX headings (`# Heading`) and Setext headings are recognized. Anchor slugs are
generated by converting the heading to lowercase, removing punctuation except
for `-` and `_`, and replacing each run of whitespace with `-`. Repeated slugs
receive numeric suffixes in document order: `section`, `section-1`, `section-2`.

Both cross-file (`guide.md#section`) and same-file (`#section`) anchors are
checked. Percent encoding in fragments is decoded before matching.

## Tests

```console
python -m unittest discover -s tests -v
python -m mdlinkcheck tests/fixtures
```

## Known limitations

- Only inline link syntax is parsed; reference-style links and autolinks are not.
- Link labels and destinations must be on one line.
- Nested parentheses and optional titles in link destinations are not parsed.
- HTML headings, explicit heading IDs, and links written as raw HTML are not
  interpreted.
- Backslash escapes inside link destinations are not decoded.
- Only UTF-8 Markdown files are supported.
